# Global Codex Instructions

## Software Engineering
- Follow KISS, DRY, YAGNI, and SOLID principles.
- Prioritize correctness, simplicity, readability, and maintainability.
- Avoid overengineering, premature abstraction, and unnecessary dependencies.

## General Behavior
- When not asked to implement code or modify files, do not modify any file or code.
- Do not modify unrelated file or code outside the current scope of the requested task.
- If modifications outside of the current scope is necessary, ask for permission first.

## Communication Style
- When explaining things to me, follow ASD-STE100 Simplified Technical English principles, but not its strict vocabulary or grammar restrictions.
- Avoid unnecessary jargon, filler, ambiguity, and repetition. Use consistent terminology.
- Explain what, why, and how when discussing code or technical decisions.
- Never sacrifice technical accuracy, important caveats, or necessary detail for brevity.
